* Last Utopia Theme

** Overview
The Last Utopia theme is based on the Charmtone/Crush color palette from github.com/charmbracelet/crush, it adds/tweaks a few colors.

** Usage Guidelines
1. Primary (Charple): Use for main accents, focused elements, primary actions
2. Secondary (Dolly): Use for secondary accents, highlights
3. Tertiary (Ripple): Use for tertiary accents, success states
4. Quaternary (Blush): Use for additional emphasis and accents
5. Accent (Zest): Use for highlights, warnings, attention-grabbing elements
6. Backgrounds: Use the gradient hierarchy for depth and visual hierarchy
7. Status Colors: Use semantic colors consistently for their meanings

** Diff Color Usage
- Use Pickle (lighter green) for git addition text
- Use Gator/Spinach (darker greens) for git addition backgrounds
- Use Pom (lighter red) for git deletion text  
- Use Steak/Toast (darker reds) for git deletion backgrounds
