* Charm Crush Theme Definition

** Overview
This theme is based on the Charm Crush color palette from github.com/charmbracelet/crush, using the Charmtone color system. It provides a cohesive dark theme experience across SwayWM, Waybar, Alacritty, and other applications.

** Implementation Notes

*** Theme Characteristics
- Dark Theme: All backgrounds use dark colors from the Charmtone palette
- High Contrast: Careful selection ensures good readability
- Cohesive: All colors come from the same palette system
- Accessible: Sufficient contrast ratios for text readability

*** Color Relationships
- Primary Triad: Charple (purple) → Dolly (magenta) → Bok (cyan)
- Background Gradient: Pepper → BBQ → Charcoal → Iron (lightest)
- Text Hierarchy: Ash → Smoke → Squid → Oyster (most to least prominent)
- Status Colors: Standard semantic colors using Charmtone equivalents

*** Usage Guidelines
1. Primary (Charple): Use for main accents, focused elements, primary actions
2. Secondary (Dolly): Use for secondary accents, highlights
3. Tertiary (Bok): Use for tertiary accents, success states
4. Accent (Zest): Use for highlights, warnings, attention-grabbing elements
5. Backgrounds: Use the gradient hierarchy for depth and visual hierarchy
6. Status Colors: Use semantic colors consistently for their meanings

*** Window Border Configuration
- Focused windows: Charple (=#6B50FF=) for clear visual indication
- Unfocused/inactive windows: Oyster (=#605F6B=) for subtle appearance

*** Media Player States (Waybar MPD Module)
- Playing: Default styling with Charple background (=#6B50FF=)
- Paused: Success state with Guac background (=#12C78F=)  
- Stopped: Inactive state with Iron background (=#4D4C57=) for visibility
- Disconnected: Error state with Sriracha background (=#EB4268=)
